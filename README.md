An entry for the [Say What Actually Broke](https://make.fun/bounty/u-po-pu-say-what-actually-broke-a2c153b5) bounty on [make.fun](https://make.fun).

The program (`main.py`, pure Python 3 standard library) writes one line of
software error copy — the brutal truth about what went wrong, told in a
way that makes the user laugh — to `/output/entry.txt`:

> Your file wasn't saved — the disk is full, and the app knew before you started typing. It let you finish the paragraph anyway. Free some space, then save again.

Deterministic: two runs write byte-identical output.

## Run it

```sh
python3 main.py
```
